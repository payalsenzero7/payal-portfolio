# Payal | Business Analyst Portfolio

A modern, responsive portfolio website built with React, Vite, TypeScript, and Tailwind CSS.

## Tech Stack

- **Framework**: React 18+
- **Build Tool**: Vite 5+
- **Language**: TypeScript
- **Styling**: Tailwind CSS 3
- **Routing**: React Router v6
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Features

- Responsive design (mobile, tablet, desktop)
- Dark mode with gradient accents
- Smooth scroll animations
- Accessible (WCAG 2.1 AA)
- SEO optimized
- Fast loading

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

### Vercel
```bash
npm i -g vercel
vercel
```

### Netlify
```bash
npm i -g netlify-cli
netlify deploy
```
